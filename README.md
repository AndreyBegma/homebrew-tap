# homebrew-tap

Homebrew formulae for AndreyBegma projects.

```sh
brew install andreybegma/tap/agentdock-runner
brew services start agentdock-runner
```

`Formula/agentdock-runner.rb` is written by the AgentDock release pipeline (`.woodpecker/release-runner.yml`) on every `runner-v*` tag. Do not edit it by hand.
